# Felipe Seabra

Personal portfolio for a Front-End focused Full-Stack Developer based in Dublin, Ireland.

Built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion and Lenis. Editorial and cinematic visual language with oversized typography, grid structure and purposeful motion.

## Development

```bash
npm install
npm run dev
```

## Quality

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```
